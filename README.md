WIRELESS COMMUNICATION AND NETWORKS

UNIT–I: Fundamentals of Wireless Communication
Introduction to wireless communication systems, evolution of wireless networks, cellular concept, frequency reuse, channel assignment strategies, propagation mechanisms, free space propagation model, path loss, shadowing and multipath fading, wireless channel characteristics.

UNIT–II: Mobile Radio Propagation and Diversity Techniques
Large-scale and small-scale fading, multipath propagation, Doppler effect, delay spread, coherence bandwidth, diversity techniques, space diversity, frequency diversity, time diversity, equalization techniques and performance improvement methods.

UNIT–III: Cellular Network Architecture and Multiple Access Techniques
Cellular system architecture, handoff strategies, roaming, mobility management, FDMA, TDMA, CDMA, OFDMA, spread spectrum techniques, capacity improvement methods, interference management in cellular networks.

UNIT–IV: Wireless Networks and Protocols
Wireless LANs (IEEE 802.11), Bluetooth, ZigBee, Wi-Fi, WiMAX, wireless sensor networks, ad hoc networks, routing protocols, medium access control protocols, network architecture and performance considerations.

UNIT–V: Advanced Wireless Communication Systems
3G, 4G LTE and 5G networks, MIMO systems, cognitive radio, software-defined radio, Internet of Things (IoT), machine-to-machine communication, network security issues, emerging trends and future wireless communication technologies.
